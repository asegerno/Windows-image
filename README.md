# Windows-image

Windows 作業系統安裝映像檔、還原鏡像與系統資源庫 (Windows OS Image Files & Installation Images).

---

## 📌 簡介 (Introduction)
本倉庫收錄 Windows 各世代作業系統之映像資源資訊、環境鏡像檔案（ISO/WIM/ESD）與安裝資源索引，主要用於系統測試、舊版軟體相容性除錯與虛擬化環境部署。

---

## 💿 映像類型涵蓋 (Image Categories)
* **現代工作站版本**：Windows 11 / Windows 10 各主要版本（24H2 / 23H2 / 22H2 / LTSC）
* **經典相容版本**：Windows 7 / Windows 8.1 / Windows Vista
* **歷史遺產環境**：Windows XP (SP2 / SP3) 專案與嵌入式系統鏡像
* **微型急救映像**：Windows PE (WinPE) 維護急救環境
